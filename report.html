Send a report

If something went wrong -- AlertKeeper stopped, a page said something you don't understand, a number looks off -- a report helps fix it. In AlertKeeper: Help → Send a report. If AlertKeeper won't open at all, write to support@alertkeeper.net.

What's in it
AlertKeeper's version, your system (macOS or Windows and its version), the data layout number, the jobs and the update steps, the last 200 lines of AlertKeeper's log, and the newest crash report if there is one.
What's never in it
A letter, a trade, a password, an email address, a file name (they can hold a person's name), an account number, or the tickers named in price lines. Each line is cleaned of them before you see it.
How it's sent
AlertKeeper sends nothing. It shows you the whole report first; Open it in my mail program starts a message to the support address with the subject filled in, and you press Send there. No mail program? Copy instead, and send it any way you like.
After a crash
The message that says AlertKeeper stopped has a Send a report button too: it opens your mail program with that crash's report.
