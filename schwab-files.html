Your Schwab files

Three files per account tell AlertKeeper your trades, what you hold, and Schwab's own gain or loss to check against. Make one set per account.

Steps

  1. On schwab.com: Accounts → History, choose the account, then Transactions. Set the date range by dates (not a preset like "Last 6 months"): from at least a year back to today -- and no later than the first close in your gain/loss file. Press Search, then Export (CSV): without Search, Export saves the range shown before, not the one you typed.
  2. Accounts → Positions, the same account, Export.
  3. Accounts → Cost Basis → Realized Gain/Loss, the same dates, Search, then Export (lot details).
  4. Repeat for each account.
  5. In AlertKeeper, Import: drop all the files on the page at once (or choose them). The first time, make the account: a name you choose and the masked number the file shows.

What you should see

  • Before saving, a count like "212 trades · 14 other rows · 0 need a look".
  • Positions lists what you hold; the positions file's check says "agree".

If it doesn't work

  • "Positions set aside: AlertKeeper couldn't work them out from your history": you sold shares bought before the history starts. Import the positions file (it places them as starting positions) or a longer history.
  • A row under Review: an action AlertKeeper doesn't know yet. It's kept as it is; nothing is guessed.
  • "This file is for account ...123, but the account chosen is ...456": choose the matching account.
  • "This file covers 4/13–10/12; your gain/loss file has closes from 1/5": the transactions file starts too late for some closes. Download it again from the day it names (Search, then Export) and import it: the comparison runs again by itself.
  • "Same as the file imported at 11:02": the file you downloaded has the same dates as one already in -- Export without Search saves the earlier range. Nothing to do but download again with Search.
  • Positions moved from another of your accounts (Schwab: Journal): they arrive with the cost and buy date from the gain/loss file, and say so.
